\begin{frame}
  \frametitle{Prompt Evaluation via Shannon Entropy}
  \begin{block}{Motivation}
    Use output diversity as a cold-start heuristic so that prompts explore broader solution spaces, not just accuracy.
  \end{block}
  \begin{itemize}
    \item For a given prompt, generate $N$ samples from the LLM.
    \item Embed each sample (e.g., CodeT5+ embeddings).
    \item Cluster embeddings (e.g., K-Means++), producing cluster proportions $p_i$.
    \item Compute entropy $H=-\sum_i p_i \log p_i$ as the diversity score.
  \end{itemize}
  \begin{block}{Intended Impact}
    Higher entropy encourages varied reasoning paths and is expected to uncover more (and subtler) bugs in code review, echoing results in \autocite{sun2025AutomaticallyDiscoveringHeuristics}.
  \end{block}
\end{frame}
