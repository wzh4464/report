\begin{columns}
\column{0.48\textwidth}
\textbf{Mixture of Experts (MoE)} 混合专家模型：
\begin{itemize}
    \item 一种稀疏建模架构；
    \item 模型由若干小的专家模型组成，每个专家擅长不同问题；
    \item 每次推理只激活其中的一小部分专家模型；
    \item 是目前性能最好的模型架构；
\end{itemize}

\column{0.48\textwidth}
\textbf{Mixture of Prompts (MoP)} 混合提示词架构：
\begin{itemize}
    \item 一种新的提示词架构；
    \item 聚合SE任务相关的提示词模板组成；
    \item 每次推理仅激活部分提示词模板；
    \item 希望能成为目前性能最优的提示词架构；
\end{itemize}
\end{columns}
