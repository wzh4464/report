\begin{frame}[fragile]
  \frametitle{What I Did Today}
  \begin{itemize}
    \item Due to the massive dataset size (235,768 files), initial tests were run on a \textbf{1\% sample} (approx. 2,350 files) using the \textbf{`kimi-k2-coder`} model to ensure feasibility.
    \vspace{1em}
    \item Deployed a structured prompt to guide the model's analysis.
  \end{itemize}
  
  \begin{block}{Core Prompt Structure Example}
    \textbf{\# Role}: You are a world-class cybersecurity expert...
    
    \textbf{\# Task}: 
    1. Step-by-step analysis...
    2. Vulnerability judgment...
    3. Vulnerability classification (CWE)...
  \end{block}
\end{frame}

\begin{frame}
  \frametitle{Challenges I Met}
    \begin{block}{Primary Obstacle: Unreliable In-Context Examples}
    The main challenge identified was the poor quality of the few-shot examples generated dynamically by the LLM itself.
    \end{block}

  \begin{itemize}
    \item \textbf{Observation}: When prompted to create its own examples for context, the model \textbf{frequently produced incorrect or logically flawed analysis}.
    \item \textbf{Negative Impact}: These erroneous examples acted as a misleading guide, significantly degrading the model's accuracy on the actual task. It essentially "learned" the wrong patterns from its own flawed reasoning.
  \end{itemize}
  
  \begin{alertblock}{Critical Issue}
    The model's performance is directly compromised by the poor quality of its self-generated examples. This introduces a high degree of variance and error into the results.
  \end{alertblock}
\end{frame}

\begin{frame}
  \frametitle{My Plan to Address the Challenges}
  \begin{enumerate}
    \item \textbf{Immediate Priority: Stabilize the Prompt}
    \begin{itemize}
        \item I will replace the dynamic, model-generated examples with a \textbf{fixed set of manually verified, high-quality examples}.
        \item This ensures the prompt provides a consistent, accurate, and reliable signal for the model to follow.
    \end{itemize}
    \vspace{1em}
    \item \textbf{Next Steps: Scale and Optimize}
    \begin{itemize}
        \item Once the prompt is stabilized, I will re-run the experiments to establish a new, more reliable performance baseline.
        \item Following that, I will incrementally increase the experiment size from the 1\% sample to larger portions of the `primevul` dataset.
        \item I will also begin researching methods for \textbf{concurrent API querying} to improve throughput for large-scale analysis.
    \end{itemize}
  \end{enumerate}
\end{frame}
