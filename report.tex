\begin{frame}
  \frametitle{Analysis 1: Scale of the PrimeVul Dataset}
    \begin{block}{Total Dataset Composition}
    The full dataset contains approximately \textbf{235,768} distinct functions.
    \end{block}

  \begin{itemize}
    \item \textbf{Vulnerable Functions}: \textasciitilde 6,968 samples.
    \item \textbf{Benign Functions}: \textasciitilde 228,800 samples.
    \item \textbf{Diversity}: The dataset covers over 140 different CWE (Common Weakness Enumeration) types, presenting a complex classification challenge.
  \end{itemize}
  
  \begin{alertblock}{Implication}
    The sheer volume of data necessitates a highly efficient and scalable processing strategy. Sequential analysis is not feasible.
  \end{alertblock}
\end{frame}

\begin{frame}
  \frametitle{Analysis 2: Token Length Requirements}
    \begin{block}{Maximum Token Length in Training Set}
    The dataset contains extremely long code samples, with the longest reaching up to \textbf{\textasciitilde 65,000 tokens}.
    \end{block}

  \begin{itemize}
    \item \textbf{Majority of Samples (Bin 1)}: 0 -- 16,384 tokens.
    \item \textbf{Fewer Samples (Bin 2)}: 16,384 -- 32,768 tokens.
    \item \textbf{Outlier Sample (Bin 3)}: At least one sample falls in the 32,768 -- 65,536 token range.
  \end{itemize}
  
  \begin{alertblock}{Critical Requirement}
    Any selected LLM \textbf{must} have a context window large enough to handle at least 65K tokens to avoid losing critical information from the most complex samples.
  \end{alertblock}
\end{frame}

\begin{frame}
  \frametitle{Conclusion: GPT-4o via API is the Optimal Choice}
  Based on the analysis, GPT-4o is the most suitable model for this task for the following reasons:
  \begin{enumerate}
    \item \textbf{Sufficient Context Window}: The GPT-4o API provides a \textbf{128K token} context window, which comfortably accommodates the longest samples in the PrimeVul dataset. This is a key advantage over lightweight models with smaller context limits.
    \vspace{1em}
    \item \textbf{High-Throughput Feasibility}: While a powerful model, the speed challenge can be overcome. By using the \textbf{API with high-concurrency requests}, we can process the entire 235,768-sample dataset in a reasonable timeframe.
    \vspace{1em}
    \item \textbf{API vs. UI Limitation}: It is crucial to use the \textbf{API}, as consumer-facing interfaces like ChatGPT or Copilot often have restricted context windows (e.g., 8K or 64K), which are insufficient for our needs.
  \end{enumerate}
\end{frame}
