\begin{frame}
    \frametitle{Metric for Prompt Evaluation: Shannon Entropy}
    \begin{block}{Referenced Paper}
        \textit{Automatically discovering heuristics in a complex SAT solver with large language models} \autocite{sun2025AutomaticallyDiscoveringHeuristics}
    \end{block}

    \begin{block}{The Core Idea: Evaluate Prompts via Code Diversity}
        Instead of using accuracy alone, we can evaluate a prompt by its ability to generate a diverse set of outputs, serving as a "cold-start" heuristic.

        \begin{itemize}
            \item For a given prompt, generate $N$ samples from the LLM.
            \item Create a vector embedding for each sample (e.g., using \texttt{CodeT5+}).
            \item Cluster the embeddings (e.g., using \texttt{K-Means++}) to group similar code reviews.
            \item Calculate the Shannon Entropy of the cluster distribution: $H(X) = -\sum p_i \log p_i$.
        \end{itemize}
        \textbf{Goal:} A higher entropy score indicates a more "creative" prompt that explores a wider solution space.
    \end{block}
\end{frame}

\begin{frame}
    \frametitle{Impact: Why Higher Diversity Leads to Better Performance}
    The paper empirically demonstrated that optimizing for diversity produced tangibly better results, a principle that directly applies to our coding review task.

    \begin{alertblock}{Key Findings and Implications}
        \begin{itemize}
            \item \textbf{Finding from the Paper:} The prompt that generated a more diverse set of potential heuristics ultimately led to a final SAT solver that performed significantly better.
                  \vspace{1em}
            \item \textbf{Implication for Coding Review:} A prompt that encourages the LLM to explore varied reasoning paths is more likely to identify a wider range of potential bugs, including subtle or uncommon ones, rather than repeatedly suggesting the most obvious fix.
                  \vspace{1em}
            \item \textbf{Benefit for EA:} This improves the exploratory power of your evolutionary search by providing a richer fitness landscape beyond simple pass/fail accuracy.
        \end{itemize}
    \end{alertblock}
\end{frame}
